What it checks

Every scan runs four engines, then merges the results into one graded report (A–F).

Rule engine

80+ offline rules across 15 languages: SQL/NoSQL/command injection, XSS, SSRF, path traversal, weak crypto, misconfiguration and more.

Secret scanner

AWS, GitHub, Stripe, Google, OpenAI keys, private keys and passwords — masked in every report.

Dependency CVEs

Checks npm, PyPI, Go, Maven, NuGet, Cargo, Composer and RubyGems packages against the OSV.dev database.

Install on Windows

Windows 10 or 11, 64-bit. The app updates itself automatically.

  1. Download the installer with the button above.
  2. Run it. If Windows SmartScreen appears, click More info → Run anyway (the installer isn't code-signed yet).
  3. Create an account in the app and start scanning. Your data stays on your PC.
  4. Updates are offered automatically when the app starts, or via Help → Check for updates.
